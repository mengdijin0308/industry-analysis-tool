连接设置

纯浏览器不能隐藏长期 API 密钥。推荐使用你控制的、已鉴权且限额的代理：真正密钥只保存在代理端。个人直连仅把密钥放在页面内存，刷新即清除。
接口、重试与提示词说明

Responses：POST {model, instructions, input, tools:[{type:"web_search"}], stream:true, store:false, max_output_tokens}。Chat：POST {model, messages, stream:true, stream_options:{include_usage:true}}。Messages：POST {model, system, messages, tools:[{type:"web_search"}], stream:true, max_tokens}，要求兼容网关支持 Bearer。

SSE 按空行分帧，支持跨网络块、多行 data 和 UTF-8。断流会从本步最近完整请求快照重新请求，替换该次尝试的临时文本，避免重复；通用流没有可保证逐 token 续传的游标。pause_turn 将原始 assistant blocks 追加到历史，最多继续 10 次。

原文存在冲突：全局禁止正文 C 档，而 Step4 要求全为 C 档；Step3 又要求未来判断。应用保持全部原文，不能承诺模型总能遵守。无检索时最高 B，需人工复核 A 档出处。

会话不落盘；刷新会丢失，请及时导出。每次请求携带全部历史以满足要求，长报告可能超出模型上下文。Token 是已报告累计值，断流且平台未返回 usage 的费用无法精确统计。
